# 脚本字符串域（字面量联合）

## 决策

上游以 `string` 承载、取值来自有限已知集合的脚本可达字段/参数，声明为：

```ts
export type ExampleDomain = "已知1" | "已知2" | (string & {});
```

并在同文件 ambient namespace re-export，供 FQN 使用。不替代已投影的 CLR 枚举 HostType。

清单与同步步骤见 [AGENTS.md](../../AGENTS.md)。

## 形态

| 规则       | 说明                                                                      |
| ---------- | ------------------------------------------------------------------------- |
| 开放回退   | 默认 `\| (string & {})`；穷尽仅当上游强校验且注释写明                     |
| 特殊字面量 | `"当前角色"`、`""` 等写在联合最前                                         |
| 成对名单   | `AvatarName` / `CombatAvatarNameEn` 同序                                  |
| 定义位置   | 贴近上游概念所在声明文件                                                  |
| 挂接       | 语义匹配的属性/参数/返回/集合元素；DSL 整串、路径、用户名保持 `string`    |
| namespace  | 每个脚本字符串域 `export type` 须 re-export；`*Family` / `*HostType` 除外 |
| 注释       | 中文 TSDoc + `@since`；注明真源与易混边界                                 |

## 何时新增

宜：脚本可达 + 可核对真源（名单 / JSON / 校验 / UI 列表）+ 单值或集合元素。  
不宜：用户自定义、路径、自由文案、DSL 整串、CLR 枚举、非闭包内部字符串。
